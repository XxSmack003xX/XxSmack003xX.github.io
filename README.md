# XxSmack003xX.github.io

Project page for [MEDIARR](https://github.com/XxSmack003xX/MEDIARR), a self-hosted dashboard for Radarr, Sonarr, Plex and SABnzbd.

Live at https://xxsmack003xx.github.io/

- `index.html`, `assets/css/mediarr.css`, `assets/js/mediarr.js`: the page. The latest version, release date and download link are read from the GitHub Releases API in the browser, so the page doesn't need editing for each release.
- `assets/fonts/`: Bebas Neue and Manrope (SIL Open Font License), self-hosted.
- `images/mediarr-icon*`: the MEDIARR app icon.
