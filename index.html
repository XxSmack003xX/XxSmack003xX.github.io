MEDIARR

One place to find, request, watch and look after the movies and shows on your media server. MEDIARR sits in front of Radarr, Sonarr, Plex and SABnzbd so your household gets one simple app and never sees an API key.

Downloadv2.3.0 View the source on GitHub

Latest release: v2.3.0, 11 October 2026. Free and self-hosted.

What it does

Find and request

Search movies and shows by title, actor, year, genre or studio. Every result shows whether it’s already in your library, and one click sends a new title to Radarr or Sonarr with your chosen quality and folder.

Admins can also browse and grab exact releases, edit monitoring, and search for missing episodes.

A home page for each person

Signed-in users land on their own page: what they were watching, what they asked for and whether it’s ready, upcoming episodes of their favourite shows, and their Plex watchlist.

Watch in the browser

Play downloaded files straight from your server or a WebDAV share. MEDIARR checks each file and picks direct play, remux or transcode on its own, with audio and subtitle tracks, quality presets, hardware encoding and resume.

Cast to Chromecast, Google TV or DLNA smart TVs from the player.

Keep the library healthy

See downloads from SABnzbd, Radarr and Sonarr in one live view. MEDIARR spots monitored titles with missing files and can queue searches to fix them, shows storage and quality across the library, and keeps a history of service outages.

Share it safely

People request access or sign in with Plex, and an admin approves them. Set daily request limits per person, hand out personal API keys, and send alerts to Discord, Slack, Telegram, ntfy, Gotify, Pushover, Pushbullet or any webhook.

Easy to run

One Docker container with no database server to set up. Automatic backups, one-click updates that roll back on their own if something goes wrong, and an installable app for phones and desktops.

Works with Radarr, Sonarr, Plex, SABnzbd, TMDB, WebDAV and Docker. MEDIARR isn’t affiliated with any of them.

Install

You need a machine with Docker and Docker Compose. Radarr, Sonarr and the rest can run anywhere MEDIARR can reach.

  1. Download the release

    Get mediarr-2.3.0.zip from the latest release.

  2. Start MEDIARR

    unzip mediarr-2.3.0.zip
cd mediarr-2.3.0
mkdir -p data
docker compose -f docker-compose.release.yml up -d

  3. Open it and set it up

    Go to http://your-server:7575, create the admin account, and follow the setup wizard to connect Radarr, Sonarr and TMDB. Everything else can be added later in Settings.

Prefer building it yourself? git clone https://github.com/XxSmack003xX/MEDIARR.git, then docker compose up -d --build in that folder. Without Docker it runs on Node.js 22.13 or newer with node server.js.

About Docker controls. The included Compose file mounts the Docker socket so admins can restart containers and update MEDIARR in one click. That access is powerful: remove the socket line if you don’t need those features, and put MEDIARR behind HTTPS before exposing it to the internet.
